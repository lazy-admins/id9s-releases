# id9s releases

Release binaries for **id9s (Identity-nines)**, a terminal UI for managing
hybrid identities (on-prem Active Directory and Entra ID) at terminal speed,
inspired by `k9s`.

Website and documentation: https://id9s.dev

## Install

macOS and Linux, via Homebrew:

```bash
brew install lazy-admins/id9s/id9s
```

Or download the archive for your platform from
[Releases](https://github.com/lazy-admins/id9s-releases/releases) and verify
it against `checksums.txt`.
